Документ фиксирует, где применялись AI-инструменты, какие результаты были отвергнуты и что проверяется машиной, а не доверием.

## 1. Инструменты и роли

| Инструмент | Роль | Использовался в решении |
|---|---|---|
| Kilo / `deepseek-flash` | генерация кода, документов, аудит исходных материалов | да, на этапе разработки |

| `rank_bm25`, `snowballstemmer` | лексический поиск | да |

В контуре принятия решения о покрытии LLM участвовал в **финальном прогоне** (`glm-5.3`, 5 вызовов): каждый его вывод проходит evidence gate, поэтому недетерминизм модели не влияет на подлинность доказательств. Offline-валидатор сохранён как детерминированный режим по умолчанию и baseline для сравнения. Эксперименты с моделями — в §7.

## 3. Отвергнутые результаты

1. **Черновой coverage report** с конкретными диапазонами строк в `medusajs/medusa` — отвергнут: репозиторий не клонировался, строки не проверялись, один «тест» был production-файлом.
2. **Первый offline-прогон (97.8%)** — отвергнут как доказательство: цифра совпала с финальной, но 3 из 20 доказательств указывали на контрольные файлы или не тот AC. Число без корректных цитат ценности не имеет.
3. **Идея «просто вызвать LLM на все тесты»** — отвергнута: 649 тестов × 5 требований, не масштабируется и не воспроизводится.
4. **Смешивание `score` BM25 и `distance` эмбеддингов** — отвергнуто после обнаружения инверсии рангов; заменено на RRF.

## 4. Что проверяется машиной, а не доверием

| Проверка | Где | Что гарантирует |
|---|---|---|
| Цитата = дословная подстрока | `validate.gate_evidence` | LLM/эвристика не может выдумать код |
| Файл = `tests/**/test_*.py` | `gate_evidence` | production-файл не станет доказательством |
| Строки внутри функции теста | `gate_evidence` | цитата относится к тесту, а не к соседнему коду |
| Числа в отчёте = числа в `report.json` | `verify` | документ не расходится с прогоном |
| Манифест ≤50 и файлы существуют | `verify` | ограничение объёма соблюдено |
| 5 требований, ≥3 AC | `verify` | структура требований не деградировала |
| Gold set ≥20, оба класса | `verify` | метрики считаются на полной разметке |
| Стабильность на 3 прогонах | `cli metrics` | результат воспроизводим |
| Подмена цитаты отклоняется | `demo/tests/test_evidence_gate.py` | gate действительно работает, а не декларируется |

## 5. Что остаётся за человеком

- **Декомпозиция требований на AC.** Модель не решает, что входит в требование; это аналитическое решение, зафиксированное в `requirements.yaml`.
- **Разметка gold set.** 35 пар размечены вручную по mutation-критерию («упадёт ли тест, если сломать поведение»).
- **Оценка адекватности доказательства.** Gate проверяет подлинность цитаты, но не её достаточность для AC.

## 7. LLM-валидация: эксперименты 2026-11-04

Ключ LLM предоставлен владельцем проекта после основного цикла работ (через локальный конфиг; в репозиторий не попадает — `.env` не коммитится). Проведён каскад из трёх режимов на идентичном пайплайне: одинаковые пулы поиска, `temperature=0`, `seed=42`.

| Режим | Модель / провайдер | Результат |
|---|---|---|
| Baseline | offline (без LLM) | 19 covered + 1 partial; Jaccard 1.0; детерминирован |
| Стресс-тест | `nvidia/nemotron-3.5-super-vl:free` (Kilo Gateway) | 16 covered; self-agreement двух прогонов 14/20 (70%); **8 неточных цитат отклонены evidence gate, 0 false positive** |
| Финал | `glm-5.3` (Z.ai) | 19 covered + 1 partial — agreement с baseline 20/20; повторный прогон 20/20; 42/42 цитат верифицированы; 5 вызовов, 138 с, 0 retry |

Выводы — как измеренные результаты, не декларации:

1. **Точность доказательств гарантируется gate, а не моделью.** На самой слабой модели система деградирует честно (covered → absent), ни одна выдуманная цитата не дошла до отчёта.
2. **Качество модели управляет полнотой и стабильностью.** `glm-5.3` воспроизвёл baseline 1:1, включая семантически аргументированный `partial` по R2.AC4.
3. Сырые ответы LLM хранятся в `run_*/llm_raw/`. Заметка честности: в ходе экспериментов обнаружено, что сначала сырые ответы писались в общий каталог и перезаписывались между прогонами — исправлено в коде до финального прогона; ответы baseline-эпохи перезаписей не касались (offline их не имеет).
